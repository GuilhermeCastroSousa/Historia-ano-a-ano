Como isto funciona / como usar

Este painel não consegue abrir o terminal sozinho — é uma trava de segurança do navegador, não uma limitação deste arquivo. Cada botão copia o comando para a área de transferência. Clique no botão, depois clique na janela do Claude Code e cole (Ctrl+V) e pressione Enter.

Para abrir o Claude Code já na pasta certa, use o catalogo.bat — um clique nele abre o terminal direto em Historia-ano-a-ano com o agente pronto.

Para abrir este painel com um clique, salve-o como painel.html na mesma pasta e crie um atalho dele na área de trabalho.
